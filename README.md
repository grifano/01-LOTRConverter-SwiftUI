# LOTR Currency Converter

A SwiftUI app that converts between the fictional currencies of Middle-earth. My first SwiftUI project — built to learn state management, bindings, and building a custom UI from scratch.

## How I built this

I learned through a structured Udemy course, then worked through the harder parts and bugs with Claude using a Socratic approach — Claude asked me guiding questions instead of handing me answers, so I had to actually reason through the SwiftUI concepts myself.
